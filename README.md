# ElementLab

118개 원소 전체를 다루는 주기율표 학습 웹앱 (라이트 모드)

## 바로 써 보기 (설치 없이)

**https://tlsgpwn.github.io/element-lab/** — `main` 브랜치의 최신 버전이 자동으로 게시됩니다.

## 세 가지 모드

- **기본**: 주기율표 보기. 원소 칸에는 기호와 그 아래 한글 이름이 나옵니다.
  - **[전형 / 전이]** 1·2·13~18족 / 3~12족(+란타넘족·악티늄족)으로 나눠 보기
  - **[금속 / 비금속]** 금속 · 비금속 · 준금속으로 나눠 보기
  - **[전기음성도]** 폴링 전기음성도 크기를 색 진하기와 숫자로 보기
  - 원소를 누르면 자세한 정보 창이 열립니다.
- **퍼즐**: 원자 번호 범위(예: 1~20, 전체 1~118)를 먼저 고른 뒤
  - **드래그 퍼즐** 원소 카드를 빈 주기율표의 올바른 칸에 끌어 놓기 (콤보·타이머·힌트)
  - **타이핑 퍼즐** 빈칸을 누르고 기호나 이름을 입력하기
- **플래시카드**: 모든 칸이 "?"이고 누르면 뒤집혀 원소가 보입니다.
  - 헷갈린 원소는 누른 뒤 **Alt + X**(맥은 Option + X)로 **오답 플래시**에 저장
  - **[오답만 복습]**으로 저장한 원소만 다시 풀기

기록(오답 플래시, 마지막 퍼즐 범위)은 브라우저 `localStorage`(`element_lab_save_v2`)에 저장됩니다.

## 내 컴퓨터에서 실행하기 (개발용)

1. [Node.js](https://nodejs.org) LTS 버전을 설치합니다.
2. 이 폴더에서 터미널을 열고 필요한 부품을 받습니다 (처음 한 번만).

   ```bash
   npm install
   ```

3. 개발 서버를 켭니다.

   ```bash
   npm run dev
   ```

4. 브라우저에서 터미널에 나온 주소(보통 http://localhost:5173)를 엽니다. 끌 때는 터미널에서 `Ctrl + C`.

## 기타 명령

```bash
npm run build    # 타입 검사 + 배포용 빌드 (dist/)
npm run preview  # 빌드 결과 미리보기
npm run lint     # 코드 검사 (oxlint)
```

## 배포

- **GitHub Pages**: `main`에 push하면 GitHub Actions(`.github/workflows/deploy.yml`)가 자동으로 빌드·게시합니다.
- **Vercel**(선택): vercel.com에 GitHub로 로그인 → **Add New → Project** → `element-lab` **Import** → **Deploy**. 설정은 기본값 그대로 두면 됩니다.
